# Dasturxon

Онлайн-меню для ресторанов Узбекистана на Next.js App Router, TypeScript и Tailwind CSS.
Реализованы лендинг, универсальный шаблон меню и три интерактивных демо.
Подготовлена и локально проверена SQL-схема Supabase. Добавлены серверное подключение и защищённый вход в панель владельца; проверка вашего реального проекта ещё требуется.

## Запуск на своём компьютере

Установите Node.js 24 LTS, откройте терминал в папке проекта:

```bash
npm ci
npm run dev
```

Затем откройте `http://localhost:3000` на своём компьютере. Терминал оставьте открытым.

Страницы:

- `/` — рекламный сайт.
- `/demo` — каталог примеров.
- `/demo/chinor` — национальная узбекская кухня.
- `/demo/kun-coffee` — кофейня.
- `/demo/olova` — бургерная.
- `/admin` — защищённый обзор платформы.
- `/admin/login` — вход администратора Supabase Auth.
- `/admin/restaurants` и `/admin/leads` — защищённые списки.

Для обновления скачанной ZIP-копии скачайте свежий архив GitHub и распакуйте в новую папку;
не стирайте свой `.env.local`. Для Git-копии используйте `git pull`, затем `npm ci`.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run start
```

Тесты используют встроенный TypeScript runner Node.js; рекомендуется Node.js 24.
Не запускайте `dev` и `build` одновременно: они используют одну директорию `.next`.
После настройки `.env.local` выполните `npm run supabase:check` для проверки подключения.
Для локального интеграционного теста входа используйте `npx playwright install chromium`, затем `npm run test:admin` после сборки. Тест использует отдельный локальный API-стаб, не вашу рабочую базу.

Локальные SQL-проверки описаны в `tests/database/README.md` и требуют Docker.

## Конфигурация и структура

- `src/config/platform.ts` — бренд, стоимость, Telegram и email. Пока цена и контакты не заданы, страница показывает честные информационные состояния.
- `src/lib/i18n/` — централизованные словари uz/ru и общий механизм сохранения языка.
- `src/components/ui/` — общие кнопки и доступные диалоги с возвратом фокуса.
- `src/components/restaurant/` — шаблон меню и каталог демо.
- `src/lib/restaurant/` — типы, детерминированное форматирование цен и фильтрация.
- `src/demo/restaurants.ts` — только демонстрационные данные, отделённые от будущей базы реальных ресторанов.
- `supabase/migrations/` — схема и RLS, применяемые отдельно от Next.js сборки.

Демо используют собственные иллюстрации с явной подписью, а не фотографии случайных блюд.
Для блюда без изображения отображается аккуратная текстовая карточка. Демо-контакты обозначены
как примеры; звонки и маршрут отключены. В реальном меню шаблон поддерживает телефонный диалог,
`tel:`, копирование номера, маршрут и социальные ссылки. Корзины, оформления заказов и бронирований внутри платформы нет.

Секреты не добавлять в конфигурацию, исходники или GitHub. `.env.local` исключён из Git.

## База данных: следующий шаг

Следуйте `docs/SUPABASE_SETUP.md`. Без Supabase демо продолжают работать.
Миграция прошла проверки в локальном PostgreSQL 17 с тестовыми схемами Auth/Storage:
права доступа, публикация, скрытые данные, изоляция, постоянные slug, цены и переводы.
Проверки настоящих Supabase API, входа администратора и загрузки файлов пока не выполнялись.
