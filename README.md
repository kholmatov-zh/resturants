# Dasturxon

Онлайн-меню для ресторанов Узбекистана. Реализован **этап 1**: структура Next.js App Router, дизайн-система и адаптивный рекламный сайт.

## Разработка

Требуется Node.js 24 (минимум Next.js — 20.9).

```bash
cd /workspace/resturants
npm ci --cache /workspace/.npm-cache
npm run dev
```

Проверки:

```bash
npm run lint
npm run typecheck
npm run build
npm run start
```

Не запускайте `dev` и `build` одновременно: они используют одну директорию `.next`.

## Конфигурация

`src/config/platform.ts`: название, цена в сумах, Telegram и email. Пока цена и контакты не заданы, страница показывает честные информационные состояния. Секреты в этот файл не добавлять.

`src/lib/i18n/dictionaries.ts`: централизованные словари узбекского и русского. По умолчанию узбекский; выбор сохраняется в localStorage. Шрифты, иллюстрации и стили не требуют внешних сервисов.

`src/components/ui`: общие кнопки и доступный Radix Dialog. `src/app/globals.css`: цветовые переменные, отступы, адаптивная сетка, состояния фокуса и reduced-motion.

## Границы первого этапа

Примеры оформления явно обозначены как макеты вымышленных заведений. Полноценные демо, меню ресторанов, заявки, база данных, администрирование и QR-коды ещё не реализованы. Изображение QR-кода не имитируется: иллюстрация показывает смартфон. Отправка заявок и фиктивные успешные ответы отсутствуют. Контакты и коммерческие условия необходимо задать перед публичным запуском.
